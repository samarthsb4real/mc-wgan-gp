A. IMPLEMENTATION DETAILS
===========================

A.1 Software and Hardware
---------------------------
  Framework:    PyTorch 2.x
  GPU:          NVIDIA GeForce GTX 1650 (4GB VRAM)
  OS:           Ubuntu 22.04
  Python:       3.10
  Key libraries: torchvision, scikit-learn, scipy, opencv-python,
                 matplotlib, seaborn, tensorboard, hypothesis

A.2 Reproducibility
--------------------
All experiments use random seed 42 for Python, NumPy, PyTorch, and CUDA.
torch.backends.cudnn.deterministic = True ensures reproducible GPU operations.
The stratified split and 5-fold CV use the same seed across all conditions.

A.3 Preprocessing Pipeline (preprocess.py)
--------------------------------------------
The preprocessing script performs the following steps:
1. Scan all (image, mask) pairs per class from data/MT_*/Imgs/
2. Pad each image to square using mean intensity as fill value
3. Resize to 128×128 using bilinear interpolation (images) or
   nearest-neighbor (masks)
4. Binarize masks at threshold 127
5. Save preprocessed files to data/processed/<CLASS>/imgs/ and masks/
6. Compute and save dataset statistics to data/processed/stats.json

Runtime: ~2 minutes on CPU for 1,344 image pairs.

A.4 GAN Training Time
----------------------
  Per epoch: ~90 seconds on GTX 1650
  100 epochs: ~150 minutes total
  Best checkpoint (epoch 26): ~40 minutes from start

A.5 Classifier Training Time
------------------------------
  Per fold: ~8 minutes (25 epochs × ~20 seconds/epoch)
  5-fold CV × 3 conditions: ~120 minutes total

B.4 FID Computation Details
-----------------------------
InceptionV3 features are extracted using a forward hook on the avgpool layer
(2048-dim). For small sample sizes, PCA reduces dimensionality to
min(n_samples - 1, 64) before computing mean and covariance.

FID formula:
  FID = ||μ_r - μ_g||² + Tr(Σ_r + Σ_g - 2(Σ_r Σ_g)^(1/2))

Numerical stability: diagonal regularization ε=1e-6 is added to covariance
matrices before matrix square root computation. Complex components with
imaginary magnitude > 0.01 are treated as degenerate (FID = ∞).
